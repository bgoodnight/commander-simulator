# V18 canonical budget deck adapter

`BudgetTable` loads the exact 100-card v1.13 budget list from `decklists/magnus_thousand_sons_v1_13_budget.txt`, including one commander and 99 library cards. The old `TutorTable` and earlier versioned tables retain their v1.6 fixtures for reproducible regression checks. The adapter is an initial integration, not a complete card database.

Twenty-nine names are absent from the legacy card catalog. They enter as inert, unverified objects with unknown types; their identities, colors and effects are not certified. This includes Frostboil Snarl, which is not yet playable as a land. Mystical Tutor is deliberately unavailable while any unknown-type card remains in its library, preventing an incomplete search from silently excluding legal choices. Existing catalog metadata has not been independently certified for the new list. Phyrexian Altar is included as a normal physical game object but its effect remains unsupported; proxy status has no rules effect.

The audit identifies gaps in cost reductions, buyback, convoke, tokens, tutor chains, Wizard/Shaman triggers and Underworld Breach. Color identity verification against authoritative card data is still required. Benchmarks for prior milestones use the old fixture and cannot be interpreted as v1.13 benchmarks. `python simulator/v18_budget_deck/tests.py` checks inventory and fail-closed behavior; `python simulator/v18_budget_deck/validate.py` runs the canonical-deck sweep.

Priority order for continued development: (1) verify identities, types and blue/red Commander color identities, (2) complete Magnus's token-based cost reduction checks against the new deck, (3) buyback and convoke payments, (4) token producers and Wizard/Shaman triggers, (5) tutor chains and (6) Underworld Breach and related graveyard casting. Phyrexian Altar needs its sacrifice-to-mana ability before combo lines can be validated. Unsupported cards remain inert rather than producing approximate printed effects.
