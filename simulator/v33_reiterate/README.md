# V33 Reiterate subset

Reiterate is a 1RR instant with optional buyback 3 and a target instant or sorcery spell. The implementation adds a nonphysical spell copy onto the shared stack; the copy resolves before the original, may be countered separately, and raises `spell_copied` rather than `spell_cast`. Buyback returns the physical Reiterate only on successful resolution, and current cost reductions apply to the complete cost. An explicit policy can change the target of supported single-target Capsize and Cyclonic Rift copies. Overloaded Rift retains overload when copied. The default pilot may copy a controlled supported spell.

This is a **partial implementation**: copies are restricted to explicitly registered copy-safe effects. General modal/multiple-target/X copies, retargeting copied counterspells, other replacements, and infinite-loop detection remain incomplete. Registered named counterspells can be copied with their original target. The cast-choice provider does not offer unimplemented targets. See `COPY_EFFECTS`, the coverage audit and source-paid interaction. Reference: [Time Spiral Remastered release notes](https://magic.wizards.com/en/news/feature/time-spiral-remastered-release-notes-2021-03-23).
