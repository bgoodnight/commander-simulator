# V32 Cyclonic Rift

`RiftTable` supports Cyclonic Rift as a 1U instant returning target nonland permanent the caster does not control, or overload 6U to return each opposing nonland permanent without targeting. The alternative cost is reduced by Magnus and Sapphire Medallion. Targets are checked at cast and resolution. Overload affects hexproof and shroud; lands and the caster's permanents stay.

The bounded engine processes the returned permanents sequentially, so effects that care about simultaneous departures are not implemented. General protection, replacement and attachment rules remain incomplete. Source: [Commander Masters release notes](https://magic.wizards.com/en/news/feature/commander-masters-release-notes).
