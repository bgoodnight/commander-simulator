The Decksmith's Forge

Build a variation in this browser. The original deck is immutable. Edits are saved locally on this device; export to keep or share them.

You can add and remove separately while drafting. Saving and exporting require exactly 100 legal Commander cards.

Draft changes

Browser versions are stored only in this browser and can be cleared by browser settings. No new simulation results are produced for edited decks.
