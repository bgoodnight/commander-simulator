How is this measured?

Run files stay in this browser and must match the selected built-in deck. Generate runs together using the same simulator version. The command below creates an array from a repository checkout.

A flagged turn follows two consecutive turns without a recorded land play, reviewed permanent, tutor, token spell or reviewed trigger resolving. Unsupported cards and unmodeled decisions can create false positives. A flag is a prompt to inspect, not a proven deck problem.

Edit Deck

Choose a built-in deck or a saved browser version. Changes stay local until you save.

Build a variation in this browser. The original deck is immutable. Edits are saved locally on this device; export to keep or share them.

You can add and remove separately while drafting. Saving and exporting require exactly 100 legal Commander cards.

Draft changes

Browser versions are stored only in this browser and can be cleared by browser settings. No new simulation results are produced for edited decks.
